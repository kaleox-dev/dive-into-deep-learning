Kinds of Machine Learning Problems

1. Regression
- supervised learning
- used to predict continous numerical values
- answers questions like "how much?" or "how many?"

2. classification
- if binary classification, model might assign probability to each class (i.e. cat or dog)
- multiclass classification for more than 2 classes (i.e. handwritten character recognition)
- common loss func for classification problems is called cross-entropy
- compute the expected detriment (weights for right and wrong)

3. tagging
- multi-label classification
    - multiple classes ("machine learning", "technology", "Linux")

4. search
- impose ranks on sets of items 
    - in web search, which results are shown more prominently to particular users?
- PageRank is a scoring system

5. recommender systems
- emphasis on personalization to specific users
- censored feedback more often (users are more likely to rate 1 or 5 stars than 3)

6. sequence learning
- how do we deal with video snippets?
- how do we ingest sentences in source language and predict translations in another language?
- require a model to ingest sequences of inputs and/or to emit sequences of outputs 
- seq2seq learning considers problems where both inputs and outputs consist of variable-length seqs

tagging and parsing
- annotates a text seq with attributes
- i.e.: in part-of-speech tagging, annotate each word in a sentence with the corresponding part of speech (noun, direct object)

automatic speech recognition
- input is an audio recording and output is a transcript of what was said

text to speech
- output is much longer than the input

machine translation
- unaligned data poses a new challenge
- determining what to say next requires taking into acc real-world knowledge and prior state of the convo across longer temporal distances

Unsupervised and Self-Supervised Learning
sup: uses labeled data to predicted outcomes (classification, regression)
unsup: uses unlabeled data to find patterns (clustering/association)
selfsup: uses unlabeled data to learn data representations (next-word preds, image completion)

Interacting with an Environment
- does the env remember what we did prev?
- does the env want to help us or beat us?
- does the env have shifting dynamics?

Reinforcement Learning
- develop an agent that interacts with the env and takes actions
- at each step:

1. the agent recieves some observation from the env
2. must choose an action that is subseq transmitted back to the env
3. recieves a reward from the env

- reinforcement learning is a Markov Decision process

Roots

key principles found in most neural nets:
- the alternation of linear and nonlinear processing units (layers)
- the use of chain rule (backprop) for adjusting params in the entire network at once

The Road to Deep Learning
- novel methods for capacity control like dropout
- Attention mechanisms
    - increase mem and complexity of a system w/o increasing the number of learnable params
- Transformer architecture 
    - performs better w/ increase in dataset size, model size, and amount of training compute 
    - used in NLP, CV, speech recognition, RL, and graph NNs
- the ability to parallelize computation has contributed to progress in RL

The Essence of Deep Learning
- the most significant commonality in DL methods is end-to-end training

Summary
- ML studies how computer systems can leverage data to improve performance at specific tasks
