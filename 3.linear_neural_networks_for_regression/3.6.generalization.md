goal is to discover patterns
- how can we be sure that we discovered a general pattern instead of just memorizing data?

overfitting:
- fitting closer to training data then the underlying distribution 

regularization methods: techniques to combat overfitting

Training Error and Generalization Error
- assume training and testing data are drawn independently from identical distributions (IID)

training error: statistic calcualted on the training dataset

$$R_\textrm{emp}[\mathbf{X}, \mathbf{y}, f] = \frac{1}{n} \sum_{i=1}^n l(\mathbf{x}^{(i)}, y^{(i)}, f(\mathbf{x}^{(i)})),$$

generalization error: expectation taken w respect to the underlying distribution

$$R[p, f] = E_{(\mathbf{x}, y) \sim P} [l(\mathbf{x}, y, f(\mathbf{x}))] =
\int \int l(\mathbf{x}, y, f(\mathbf{x})) p(\mathbf{x}, y) \;d\mathbf{x} dy.$$

- can never calculate generalization error
- can estimate it by applying model to independent test set


Model Complexity
- cannot conclude that model has discovered generalization pattern after fitting training data alone
- models with more params are not necessarily always able ot fit a greater number of arbitrarily assigned labels

weight decay: regularization technique

- low training error does not necessarily imply low or high generalization error 
- rely more heavily on holdout data to certify generalization after the fact (validation error)

Underfitting or Overfitting?
case 1: where training error and validation error are both substantial but little gap between them 
- if model is unable to reduce training error, it means its too simple
- underfitting

case 2: training error is significantly lower than our validation error
- overfitting
- not always a bad thing

Polynomial Curve Fitting
given training data consisting of a single feature $x$ and a corresponding real-valued label $y$, try to find a poly of degree $d$

$$\hat{y}= \sum_{i=0}^d x^i w_i$$

Dataset Size
- the fewer samples in the training dataset, the more likely to overfit
- as increase training data, the generalizatione error typically decreases
- mostly, DL only outperforms linear models when there are thousands of training data available

Model Selection
split data three ways:
1. training set
2. testing set
3. validation set

Cross-Validation
K-fold cross-validation

- split original training data into $K$ non-overlapping subsets
- model training and validation are executed $K$ times, each trainng on $K-1$ subsets and validating on a different subset (the one not used for training that round)
- training and validation errors are estimated by avg the results from $K$ experiments

Summary
1. use validation sets for model selection
2. complex models need more data
3. complexity include # of params and range of vals they can take
4. more data almost always leads to better generalization
5. predicated on IID assumption
